Mark referral orders for Kostas (customers see nothing)

Christos’s promo site sends shoppers with ref=christos-solonos. After you install the snippet below, those orders will show in Shopify Admin that the client was referred by Christos Solonos. Shoppers will not see any message.

Where you see it:
Shopify Admin → Orders → open the order → Additional details / cart attributes

Referred by: Christos Solonos
Referral note: Referral client from Christos Solonos promo site

Install once on Shopify

  1. Open project file shopify-christos-referral.liquid
  2. Shopify Admin → Online Store → Themes → Edit code
  3. Snippets → Add a new snippet named christos-referral
  4. Paste the file contents → Save
  5. Open layout/theme.liquid
  6. Just before </body> add:
{% raw %}{% render 'christos-referral' %}{% endraw %}
  1. Save
  2. Test with a promo-site product link, add to cart / place a test order, check Additional details

Optional: email yourself on referral orders

Shopify Flow → Order created → if cart attribute “Referred by” contains Christos Solonos → Send internal email: “Referral client from Christos Solonos”.
